### M0 のメモ

**`@types/node` を入れなかった理由。** `PROMPT.md` §1 は「devDependencies は typescript のみ」を
交渉不可としている。`@types/node` を入れると違反するので、使う API だけを
`types/node-builtins.d.ts` に自前で宣言した。テストは型検査の対象のまま保てている。

**テストの実行方法。** `tsc` で `dist/` に出してから `node --test "dist/tests/*.test.js"`。
Node の型ストリップに頼らないので実験的機能を使わずに済む。`npm test` がこれを行う。

**残っている軽微な不具合（隠さず記録）**
- takaya swing_1 の膝付近に小さな白い破片が1つ残る（チョーク線の残骸、数十px）
- 顔素材のうち takaya_profile / takaya_thinking の右端にパネル枠の細線がわずかに入る
- `anchors.json` は自動算出値で、左右の足の高さが違うコマでは重心が寄る
  （例: yuki/stance は x=283/幅337）。**M2 と M4 で目視補正する前提**（SPEC §10-5）

> **経営者が挟まる工程。** ここでズレていたら以降が全部崩れる（`PROMPT.md` 手順4）。
